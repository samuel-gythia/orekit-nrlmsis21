## 3. Storm-Time vs. Daily Ap Behavior & `pymsis` 2.1 Parity

Tested in `tests/test_cssi_adapter_verification.py` (Windows) and `LinuxJniValidation.java` (Linux):
- **Controlled Synthetic Ap Sensitivity Test (Windows, 400 km)**:
  - In **Storm Mode (`sw(9) = -1.0`)**: Changing `ap[1..6]` from `[15, 15, 15, 15, 15, 15]` (`rho = 4.068830e-12 kg/m^3`) to `[15, 400, 400, 400, 400, 400, 400]` (`rho = 1.492877e-11 kg/m^3`) produces a **`+266.91%`** storm response.
  - In **Daily Mode (`sw(9) = +1.0`)**: Both inputs return identically `3.967283e-12 kg/m^3`, confirming `ap[1..6]` are ignored as required.
- **Historical & Extreme Geomagnetic Epochs vs. `pymsis.calculate(..., version=2.1)` (Windows)**:
  - Quiet Solar Min 2008 (`2008-01-15T06:30:00`): storm vs daily delta `8.63%`, `pymsis` rel err `5.08e-06` (storm) / `1.88e-06` (daily)
  - Quiet 2020 (`2020-06-21T00:00:00`): storm vs daily delta `3.05%`, `pymsis` rel err `1.95e-06` / `1.36e-06`
  - Moderate Cycle 24 (`2014-04-11T18:00:00`): storm vs daily delta `2.40%`, `pymsis` rel err `5.75e-07` / `1.80e-07`
  - Halloween Storm 2003 (`2003-10-29T07:30:00`): storm vs daily delta `10.82%`, `pymsis` rel err `8.16e-06` / `2.11e-06`
  - Gannon Storm 2024 Peak (`2024-05-11T01:30:00`): storm vs daily delta `2.56%`, `pymsis` rel err `4.15e-06` / `2.65e-06`
  - Gannon Storm 2024 Post (`2024-05-12T06:00:00`): storm vs daily delta `30.70%`, `pymsis` rel err `1.99e-07` / `6.69e-07`
- **CSSI Density Equivalence**: `CssiWeatherProvider`, `ConstantSpaceWeather`, and `ConstantSpaceWeather.ofDailyAndAverage` yield bit-identical densities across `150..600 km` on all 6 epochs (Windows), and verified on Linux OpenJDK 17 at 400 km (`rho = 6.144093e-12 kg/m^3`).

## 4. Orekit `Atmosphere` & Batch Least Squares (BLS) Validation

- **`tests/test_orekit_atmosphere.py` (`8/8` passing on Windows)**:
  - Monotonic density profile from `150 km` (`1.95827e-09 kg/m^3`) to `800 km` (`3.65083e-14 kg/m^3`).
  - Altitude domain checks: `< 0 km` clamps to sea-level density; `> maxAltitudeKm` returns `0.0`.
  - Atmosphere velocity (`2026-10-25T12:00:00 UTC`): `v_atm ITRF = 0.000e+00 m/s`, `v_atm GCRF = 494.268 m/s` (matching theoretical $\omega r = 494.270\text{ m/s}$).
  - `Field` `getVelocity` Coriolis partials: Frobenius norm `1.031261e-04` matching $\sqrt{2}\omega = 1.031261\text{e-}04$.
  - `Field` `getDensity` spatial gradient & `DragForce(atm, sc, false)` sensitivity verified against numerical finite differences.
- **`tests/test_batch_least_squares.py` (Windows Gauss-Newton BLS)**:
  - Scenario: 500 kg spacecraft, $A = 2.0\text{ m}^2$, true $C_d = 2.20$, 400 km circular LEO ($i = 51.6^\circ$), 720 synthetic GCRF Cartesian position measurements over 12 hours ($\Delta t = 60\text{ s}$, $\sigma = 1.0\text{ m}$), perturbed a priori orbit ($\Delta r_0 = 173.205\text{ m}$, $\Delta v_0 = 0.17321\text{ m/s}$, $C_{d,0} = 1.60$).
  - Results: Converged in **4 iterations / 4 evaluations** (`31.555 s`), **Normalized Cost RMS = `0.9950`**, **Position Residual RMS = `1.723 m`** (theoretical 3D $\sqrt{3}\sigma = 1.732\text{ m}$), final initial-state error **`0.146 m`** (`3σ: 0.408 m`) and **`0.00014 m/s`** (`3σ: 0.00044 m/s`), recovered **`Cd = 2.2000`** (**`0.0015%` error**, `3σ: 0.0012`).
